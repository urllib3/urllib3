Allowed dots in URL schemes parsed by ``urllib3.util.parse_url()``, so URLs
such as ``a.b://example.com/path`` are no longer read as schemeless. Schemeless
URLs with a port, such as ``example.com:8080``, keep being parsed as a host and
port, and invalid host and port input such as ``example.com:8080;foo`` keeps
raising ``LocationParseError`` instead of being read as a scheme.

Fixed a denial-of-service issue where a malicious server could cause unbounded memory usage in the streaming chunked-transfer-encoding read path (``HTTPResponse.stream()`` / ``HTTPResponse.read_chunked()``) by sending an unterminated chunk-size line. The chunk-size line and trailing CRLF are now read with a bounded length matching :data:`http.client._MAXLINE`, raising :class:`~urllib3.exceptions.ProtocolError` if exceeded, consistent with the non-streaming ``HTTPResponse.read()`` path.
